# 云与容器（`11-cloud`）

_Kubernetes、容器逃逸_

## kubernetes-pentesting  `P1`

Kubernetes 渗透测试。当需要通过 API Server、RBAC 枚举、服务账号滥用、etcd 访问、Kubelet API、Pod 逃逸、云元数据、准入 webhook 绕过与镜像仓库密钥攻击 K8s 集群时使用。

## container-escape-techniques  `P1`

容器逃逸。当已在 Docker 容器、LXC 或 Kubernetes Pod 内部，需要通过特权模式、capabilities、Docker socket、cgroup 滥用、命名空间技巧或运行时漏洞逃逸到宿主机时使用。
